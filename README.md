# Afterglow Shift

Восстановленный прототип на **Python / Pygame CE** по исходному архиву и записи начала игры от 28 апреля 2025 года. Портретная сцена 576 × 1024, пиксельная графика, параллакс и постепенное появление текста.

## Запуск на компьютере

Нужен Python 3.10–3.13. Из терминала:

```sh
git clone https://github.com/dschkn/afterglow_shift.git
cd afterglow_shift
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

В Windows вместо `source .venv/bin/activate` используйте `.venv\Scripts\activate`.
Пути привязаны к проекту: запуск через IDE или из другой папки также работает.

## Что можно пройти

**Главное меню → город с параллаксом → две страницы вступления → комната → входящий звонок → ответ зелёной кнопкой.**

- Титульный экран и музыка плавно появляются; первый клик позволяет ускорить появление меню.
- `new game` начинает вступление. `settings` включает и отключает звук.
- Город состоит из пяти исходных слоёв, движущихся с разными скоростями.
- Строки текста появляются каждые шесть секунд и остаются на экране, как в записи.
- Во вступлении клик / касание / Space / Enter сначала раскрывает текущую страницу, следующий переводит дальше.
- В комнате воспроизводятся 39 исходных кадров. Вместе со звонком появляется «[Ответить на звонок]», снизу выезжает крупная Nokia с пиксельным LCD.
- При звонке телефон выезжает снизу с надписью «Входящий вызов». Ответить можно только нажатием на зелёную трубку. После ответа звонок прекращается; телефон остаётся на экране. Продолжение диалога пока не добавлено.
- `Esc` возвращает в меню; в меню закрывает приложение. `M` переключает звук.
- Окно можно растягивать: изображение сохраняет пропорции, свободное место заполняется чёрным.

## Организация проекта

| Путь | Что хранится |
| --- | --- |
| `main.py` | Единственная точка входа |
| `game/app.py` | Окно, главный цикл, переключение сцен, ввод |
| `game/scenes/` | Поведение меню, вступления и комнаты |
| `levels/intro/scene.json` | Текст, скорости слоёв, тайминги, затемнение |
| `levels/intro/assets/` | Пять слоёв конкретной сцены |
| `levels/bedroom/scene.json` | FPS кадров и время звонка |
| `levels/bedroom/assets/` | Кадры комнаты и телефон |
| `assets/` | Общий шрифт, музыка, титульная картинка |
| `source_materials/` | Сохранённые заготовки Tiled и исходные наборы фонов |
| `docs/legacy/` | Старые скрипты и заметки как справочные `.txt` |
| `docs/source_inventory.json` | Все исходные файлы, SHA-256 и соответствия новым путям |
| `tests/` | Проверки полного маршрута, ввода и загрузки |

**Принцип:** уникальные ресурсы живут рядом с данными уровня, общие — в `assets/`; код сцены — в `game/scenes/`. Уровень больше не запускает другое приложение через `exec()`.

Чтобы изменить скорость города или текст, редактируйте `levels/intro/scene.json`. Чтобы добавить следующую сцену, создайте класс с `update`, `draw`, `activate`, добавьте его в `SCENES` в `game/app.py` и вызывайте `app.change('имя')`. Инициализировать Pygame заново не нужно.

## Статус восстановления

Подробности: [RESTORATION.md](docs/RESTORATION.md).

Это **настольный прототип с портретным экраном и поддержкой событий касания**, а не готовый APK/IPA. На реальном телефоне не тестировался. Для мобильного релиза ещё нужны выбранный способ упаковки, работа с жизненным циклом приложения, проверка звука и памяти на устройстве. Все кадры комнаты сейчас загружаются в память заранее (~92 МБ RGBA без учёта прочих ресурсов).

## Проверка

```sh
python -m unittest discover -s tests -v
python main.py --headless --frames 5
python main.py --scene intro
python main.py --scene bedroom
```

Для воспроизводимого снимка:

```sh
python main.py --headless --scene intro --frames 65 --fixed-dt 1 --screenshot intro.png
```

GitHub Actions запускает тесты на Python 3.10, 3.12 и 3.13. Локально проверено на Python 3.12 / SDL dummy; визуальные кадры просмотрены отдельно. Реальное воспроизведение звука и macOS/Windows/телефон требуют проверки на устройстве.

Большая дорожка `Symmetry.mp3` хранится двумя `.part`-файлами из-за ограничения загрузки GitHub API. Игра соединяет их в памяти автоматически: звук не перекодировался.

## Исходные материалы

Графика, шрифт и звук перенесены из предоставленного автором архива без назначения новой лицензии. Сохранённые лицензии наборов находятся в `source_materials/`. В исходных заметках для части музыки указан https://incompetech.com/music/royalty-free/music.html; полной атрибуции для всех ресурсов в архиве нет. Этот репозиторий не утверждает, что сторонние материалы стали свободно лицензированными.

## Исправление отображения на macOS (1 ноября 2026)

Если вместо букв были чёрные полосы, а фон отсутствовал, обновите проект:

```sh
git pull --ff-only origin main
python main.py
```

Для скачанного ZIP нужно скачать обновлённый архив репозитория и распаковать в новую папку.
Изменён весь путь отрисовки: непрозрачный RGB-кадр, явные RGBA-ресурсы,
SDL2-смешивание для изображений, текста и затемнений. Нулевое затемнение больше
не рисует дополнительную поверхность. Новые тесты проверяют пиксели фонов,
букв и итогового кадра. Локально прошли 12 тестов на Linux; исходный дефект на
Mac пользователя здесь не воспроизведён, поэтому исправление требует проверки
на этом устройстве. CI также настроен на macOS и Windows.

## Обновление телефона и графики

Новый стартовый фон сохраняет пиксельную эстетику и исходную композицию.
Надпись автора на стене скрывается небольшим восстановленным фрагментом;
сама 39-кадровая анимация сохранена. Информация об исходнике: `docs/ART_ASSETS.md`.
Громкость рингтона снижена с 0.65 до 0.18 и сохраняется после выключения/включения звука.
В `levels/bedroom/scene.json` регулируются `ring_gain` и `phone_slide_seconds`.

## Запись Роя и читаемость

Звонок начинается через 7 секунд после входа в комнату. Зелёная трубка выключает
рингтон и один раз воспроизводит `assets/audio/roy_call.mp3` (исходная запись
пользователя без обработки) с громкостью 35%. На время речи дождь снижен до 18%.
`M` отключает оба звука, выход в меню останавливает речь. Громкость регулируется
через `voice_gain` и `voice_background_gain` в `levels/bedroom/scene.json`.
Основной шрифт увеличен с 16 до 20 px, текст LCD — с 16 до 18 px перед удвоением.
Стартовая картинка заменена присланным тёмным вариантом, без перерисовки.
